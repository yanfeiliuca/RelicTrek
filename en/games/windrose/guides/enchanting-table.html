1. What We Can Verify

The Enchanting Table is a Cursed Swamps-era crafting station tied to Arborum materials. Current public guides support its build cost, roof / Bonfire placement requirement, and broad Ingot Arborum relationship, but they do not settle every route, weapon cost, or combat-value claim.

Use this page as a source-checked checklist. If a field depends on a current item panel, exact drop count, route timer, or weapon mechanic, it is treated as 待确认 until stronger evidence is available.

Sources also disagree on the exact unlock trigger. GAMES.GG connects the table to Ancient Scraps, Method.gg frames enchanting around Plague Wood and Essence Arborum, and GAMES.GG's Ingot Arborum page says first Essence Arborum unlocks the table recipe.

2. Materials Checklist

The top-level build cost is consistent across the checked guide sources: 3 Mire Metal Ingots, 10 Hewn Stone, 10 Plant Fiber, and 2 Essence Arborum.

To Use the Enchanting Table, You Also Need:

  • A roof directly above the table
  • A Bonfire within proximity

Both conditions are repeated in multiple checked sources. If the table does not activate, confirm the sheltered / roof state and the Bonfire range before assuming a missing material.

3. Conservative Setup Order

This is not a timed route. It is a conservative order for checking the source-backed requirements without repeating unsupported route-duration claims.

1Enter the Cursed Swamps carefully. Current sources place the relevant material chain in or around this biome, but this page does not certify a minimum gear level or fixed difficulty rating.
2Collect Ancient Scraps. Sources connect Ancient Scraps to ruins / debris and to the table's surrounding recipe chain; the exact unlock trigger remains 待确认.
3Collect Plague Wood. Current sources connect Plague Wood to Essence Arborum. Exact yield and enemy-drop details are not fixed here.
4Prepare the listed build materials. Confirm the current recipe UI for Mire Metal Ingot, Hewn Stone, Plant Fiber, and Essence Arborum before spending rare materials.
5Build under the required conditions. Place the table under a roof / sheltered state and near a Bonfire or heat radius.
6Check the table's current output list. Sources differ on whether the table currently lists only Ingot Arborum or multiple Arborum outputs.
7Record unresolved fields. Drop exclusivity, fixed quantities, and weapon upgrade totals should stay 待确认 without current UI evidence.

5. What the Sources Say It Can Craft

Checked sources agree that Ingot Arborum is central. They differ on whether Fabric Arborum and Hide Arborum should be treated as current table outputs in the same way.

  • Ingot Arborum — linked by current guides to plague weapons and Bullet Arborum
  • Fabric Arborum — listed by some sources; verify in the current table UI
  • Hide Arborum — listed by some sources; verify in the current table UI

Bullet Arborum and plague weapons are propagation candidates, but exact ammo effects, weapon costs, and upgrade totals need a separate source pass.

6. Getting Started

The practical first step is to enter the Cursed Swamps material chain and verify the current unlock trigger in your save. Ancient Scraps, Plague Wood, Essence Arborum, and the table recipe are the checkpoints to watch.

  • Do not overstate timing. This page no longer claims a fixed route duration.
  • Check Fast Travel wording separately. Prior Windrose audits found coastal placement limits for Fast Travel Points, so do not write that bells can be dropped anywhere inland without verification.
  • Build after verifying materials. Confirm the current recipe UI before committing scarce Cursed Swamps resources.
  • Keep weapon ranking separate. Tumbaga, Arborum, and plague weapon claims require their own source matrix.
