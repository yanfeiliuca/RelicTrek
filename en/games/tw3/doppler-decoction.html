1. Why You Need This

Witcher 3's skill system forces a structural choice: Fast Attack skills boost fast attacks. Strong Attack skills boost strong attacks. A mixed build loses some bonuses from each tree on the "wrong" attack type. The Doppler Decoction removes this restriction while active — skill bonuses from both trees apply simultaneously regardless of which attack type Geralt uses.

The Doppler is found in Novigrad during "An Elusive Thief." When Geralt confronts it: Fight it → it dies → drops Doppler Mutagen → you get the decoction. Let it flee peacefully → it escapes → no body → permanently unavailable. There is no other Doppler that drops this mutagen in the base game or either DLC.

2. Decoction Effect

While active: Skill bonuses from Fast Attack and Strong Attack trees both apply simultaneously to any attack type. A build with investment in both trees deals full bonus from both on every hit. Toxicity cost: 40.

Best for: Any build that invests in both Fast and Strong attack trees rather than specialising fully in one.

3. "An Elusive Thief" Quest

Quest location: Novigrad, middle portion of Act 2. Available from the Novigrad notice board or a specific merchant. A Doppler has been impersonating a local merchant. Track it through Novigrad using Witcher Senses. The confrontation: the Doppler reveals itself — it is sapient and did not intend harm.

Option A (Fight): Defeat it in combat. It drops the Doppler Mutagen. To get the mutagen, choose this option.

Option B (Let go): The Doppler makes a case to be spared. Agree. It leaves. Alternative reward given (crowns, information). No mutagen. No second chance.

4. Hazard Guide

⚠ ONE-TIME ONLY

Once the Doppler escapes, it is gone from the game forever. The mutagen cannot be obtained through any other means. If you want the decoction, choose to fight.

⚠ The Fight

It copies your appearance and moveset but lacks your equipment quality. Quen, standard combos — straightforward. It does not use Signs.

5. Comparison With Other Missables

Like the Succubus Decoction, the Doppler Decoction requires choosing combat over peaceful resolution. Together with the Olgierd/Gesheft choice, TW3 has several "information-first" decisions where knowing the weapon/mutagen consequences in advance changes the decision from purely narrative to informed.

6. The Mixed-Build Enabler

The Doppler Decoction enables the only build archetype the game's skill system structurally discourages: the true hybrid warrior who uses both fast and strong attacks situationally without being penalised for spreading skill points across both trees. That it requires permanently losing a peaceful resolution option makes it one of the most consequential crafting decisions in the game.
