1. Quick Answer

Short Version

The base game has 16 records for the Golden Melody route: 11 standard records tied to quests, merchants, or Eugenie / Alidoro, plus 5 Golden Records from NG+ vendors. Current patched versions allow formerly mutually exclusive Records to be acquired in one playthrough, but Golden Records still require NG+.

You cannot safely treat records as simple pickups. Several are quest rewards, some require buying from temporary Wandering Merchants, and the Eugenie / Alidoro pair is still route-sensitive even if it no longer automatically forces a second cycle on current patches. The safest plan is to collect every standard record you can, play new records at Hotel Krat, then use NG+ for Golden Records and any missed older-version branch cleanup.

5. Safe Two-Cycle Route

Run 1Collect quest records: Feel, Divine Service, Someday, Fascination, Quixotic, Why, Misty E'rA, Memory of Beach, Shadow Flower, and the Eugenie / Alidoro records available on your patch.
Run 1Play as you go: use the Hotel Krat gramophone after major record pickups to support Humanity and avoid endgame confusion.
Run 1Do not start NG+ immediately: check Hotel Krat, Antonia's wheelchair, Sophia's room, and the gramophone first.
Run 2Buy Golden Records early: Cerasani Alley and Elysion merchants are easy to miss if you rush bosses.
Run 2Clean up only if needed: if an older version, missed dialogue state, or unpatched route left one Eugenie record missing, route Alidoro and Eugenie again.
Run 2Finish late merchant cleanup: get Abandoned Apartment and Test Subject 826 records before ending the cycle.

7. Common Mistakes

Missing Adelina's Apple

Buy Bright Red Apple from Polendina and give it to Adelina before King of Puppets. Fascination depends on this window.

Skipping Antonia's Cure

Memory of Beach depends on Antonia's cure route. Keep Polendina, Giangio, and Antonia updated after Champion Victor.

Treating Eugenie as One Dialogue

Eugenie's record route is branch-sensitive and patch-sensitive. Read Alidoro-related items, preserve a save, and use NG+ only if one branch remains missing after checking your record inventory.

Forgetting NG+ Vendors

Golden Records are mostly merchant purchases. Buy them immediately instead of assuming you can come back later.

9. FAQ

How many records are in the Lies of P base game?

The base-game Golden Melody route uses 16 records: 11 standard records and 5 Golden Records. A clean completion plan still needs NG+ because the Golden Records are NG+ vendor purchases.

Can all records be collected in one playthrough?

No for the full Golden Melody set, because Golden Records require NG+. On current patched versions, formerly mutually exclusive records can be acquired in one playthrough, so the Eugenie branch itself should be treated as patch-sensitive rather than automatically NG+.

Do records increase Humanity?

Yes. Records are one of the main Humanity supports. Play new records at Hotel Krat rather than only collecting them in your inventory.

Which records are easiest to miss?

Fascination, Divine Service, Why, Memory of Beach, the Eugenie / Alidoro records, and early NG+ merchant records are the main danger points.

Do Overture DLC records count for Golden Melody?

Treat Overture as a separate DLC record checklist. The DLC has its own record set and Memory's Melody route, while this page keeps the base-game 16-record route clear.
