一、当前可确认内容

附魔台是与诅咒沼泽和 Arborum 材料相关的合成站。当前公开攻略可支持其建造材料、屋顶 / 篝火摆放条件，以及它与阿博鲁姆锭的大方向关系，但不能支撑所有路线、武器成本或战斗数值。

本页作为来源核验清单使用。凡是依赖当前物品面板、精确掉落数量、路线耗时或武器机制的字段，在取得更强证据前均标为待确认。

来源对精确解锁触发并不一致：GAMES.GG 将其与 Ancient Scraps 联系起来；Method.gg 更强调 Plague Wood 与 Essence Arborum；GAMES.GG 的 Ingot Arborum 页面则写 first Essence Arborum 会解锁附魔台配方。

二、部件清单

已核对来源对顶层建造材料基本一致：3 个 Mire Metal Ingot、10 个 Hewn Stone、10 个 Plant Fiber、2 个 Essence Arborum。

材料获取方式
Ancient Scraps诅咒沼泽废墟 / 遗址来源；具体解锁作用存在来源差异
Mire Metal Ingot ×3当前攻略将其与 Ancient Scraps 和 Quagmire Powder 联系起来
Hewn Stone ×10列为建造材料；来源文本将其与普通石头合成联系起来
植物纤维 ×10砍伐任何岛屿上的树木和灌木
Essence Arborum ×2当前攻略将其与 Plague Wood 联系起来

使用附魔台还需要：

  • 工作台正上方有屋顶
  • 附近有篝火

多个来源重复提到这两个条件。若附魔台无法激活，先检查遮蔽 / 屋顶状态和篝火范围，再判断是否缺少材料。

三、保守设置顺序

以下不是计时路线，而是按当前来源复核要求的保守检查顺序，避免继续传播未核验的固定耗时。

1谨慎进入诅咒沼泽。当前来源将相关材料链放在该区域附近，但本页不确认最低装备等级或固定难度。
2收集 Ancient Scraps。来源将 Ancient Scraps 与废墟 / 遗址及附魔台周边配方联系起来；精确解锁触发仍待确认。
3收集 Plague Wood。当前来源将 Plague Wood 与 Essence Arborum 联系起来；具体产量和敌人掉落细节不在本页固定。
4准备已列出的建造材料。投入稀缺材料前，先在当前版本 UI 中核对 Mire Metal Ingot、Hewn Stone、Plant Fiber 和 Essence Arborum。
5按条件放置。附魔台需要屋顶 / sheltered 状态，并需要附近有篝火或热量范围。
6检查当前产出列表。来源对附魔台当前是否同时列出多种 Arborum 产物存在差异。
7记录待确认字段。掉落排他性、固定数量和武器升级总数，若无当前 UI 证据，继续标为待确认。

四、风险提示

⚠️ 避坑指南

⚠️ 风险1 — 解锁触发表述漂移

不要把某一个材料写成固定触发点。已核对来源分别提到 Ancient Scraps、Plague Wood 和 first Essence Arborum。

屋顶 / sheltered 状态与附近篝火条件有来源支持。若台子不工作，先检查这些状态。

⚠️ 风险3 — 精确路线断言

路线耗时、固定单轮产量和最优循环仍是当前补丁待确认内容。

五、来源如何描述产出

已核对来源都强调 Ingot Arborum 的重要性，但对 Fabric Arborum 和 Hide Arborum 是否同等作为当前附魔台产出，表述并不完全一致。

  • Ingot Arborum — 当前攻略将其与瘟疫武器和 Bullet Arborum 联系起来
  • Fabric Arborum — 部分来源列出；以当前台子 UI 为准
  • Hide Arborum — 部分来源列出；以当前台子 UI 为准

Bullet Arborum 和瘟疫武器是后续传播回扫对象；弹药效果、武器成本和升级总数需要单独来源矩阵。

六、快速上手建议

实际第一步是进入诅咒沼泽材料链，并在当前存档中复核解锁触发。Ancient Scraps、Plague Wood、Essence Arborum 和附魔台配方是需要观察的检查点。

  • 不要传播固定耗时。本页不再声称固定路线时长。
  • 快速旅行说法需单独复核。此前 Windrose 审计已记录 Fast Travel Point 有海岸放置边界，不能直接写可把铃铛放在任意内陆遗址。
  • 先核对材料再建台。投入稀缺诅咒沼泽资源前，先确认当前配方 UI。
  • 武器排名单独处理。Tumbaga、Arborum 和瘟疫武器之间的关系，需要独立来源矩阵。
