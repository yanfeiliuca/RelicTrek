关键节点

1. 为什么需要

马天霸（Ma Tianba）是黑神话悟空中最容易被忽视的NPC之一。他不是Boss，没有血条，没有地图标记。他只是在每一章中默默站在角落里，等待一次对话——如果你不主动找他，他甚至不会出声。

但他是解锁Dark Thunder / 黯雷变化术的唯一途径。在全部10种已核实变化术中，黯雷需要横跨五章完成马天霸任务链。漏掉关键对话或第五章火焰山节点，可能导致本周目无法取得。

需要先纠正一个旧错误：Dark Thunder 的官方英文名对应黯雷，它就是马天霸任务链奖励。此前页面把相近写法拆成两种不同变身，这是不正确的；本页统一按 Dark Thunder / 黯雷 处理。

2. 它是什么

Dark Thunder / 黯雷：变化术。天命人变成马妖，使用雷鞭攻击，能造成雷蛰 / Thunder Bane，并在变化期间免疫雷属性伤害。它不是另一条同名近似路线，而是马天霸五章任务链的最终奖励。

属性说明
变身类型雷属性 · Dark Thunder / 黯雷
获取方式马天霸任务链——第一章至第五章，每章一次对话
命名校正Dark Thunder 对应黯雷；不要再把近似写法作为另一种变化术计入清单
核心效果马妖形态、雷鞭攻击、雷属性免疫、雷蛰积累

3. 前置条件

无硬性前置条件。马天霸从第一章即可遇到。但必须在每一章推进主线前先找到他并对话至台词耗尽——这是最重要的要求。

⚠️ 对话耗尽原则

每次找到马天霸，他可能有2-4句对话。你必须反复与他交谈，直到他开始重复最后一句台词。只谈一次就走是玩家断链的最常见原因。

🕐 关键风险

能回头补对话时应立即补齐。来源明确指出的高风险节点在第五章：击败火焰山土地前，需要先在火燎谷谷口路线找到被困战车中的马天霸并完成互动，否则任务可能无法完成。

4. 路线指南——逐章追踪

第一章——翠竹林后山

1从翠竹林·后山出发，沿路进入小洞 / 建筑区域寻找马天霸。
2与他对话到台词重复。
3与他对话至台词耗尽（约3轮对话）。他提到在寻找什么——这是任务链的起点。

第二章——沙门村

1进入沙门村后，沿地狼附近的区域寻找被鼠妖困住的马天霸。
2击败地狼后再与他对话，直到台词重复。
3对话至耗尽。他会提到接下来要去一个有塔的地方。

第三章——小西天 / 新雷音寺

1到达新雷音寺·寺门后，从主建筑和侧楼梯路线进入侧殿。
2在二层长廊 / 桥状通道附近找到马天霸。
3对话至耗尽。

第四章——盘丝洞 / 盘丝岭

1击败蜈蚣精后继续推进，在主路附近的大茧中找到被困的马天霸。
2释放并对话至耗尽。他会继续前往火焰山。

第五章——火焰山（最终）

1击败阴阳鱼后，从火燎谷·谷口路线返回，在熔岩区域旁的战车处找到被困的马天霸。
2先完成战车 / 鞭子的互动，再推进火焰山土地战。
3击败火焰山土地后回到战车终点，完成马天霸任务并获得Dark Thunder / 黯雷变化术。
🏆 奖励确认

完成五章对话与第五章战车节点后，最终奖励为 Dark Thunder / 黯雷变化术。

5. 风险与应对

🔴 风险1：只对话一次

玩家容易误以为谈过一次就算完成；更稳妥的做法是反复交谈直到他开始重复台词，再推进下一段主线。

🔴 风险2：第五章顺序错误

击败火焰山土地前，先在火燎谷战车处找到马天霸并完成互动。来源记录显示，如果先击败火焰山土地，任务可能无法完成。

🔴 风险3：名称误读

Dark Thunder 对应黯雷。不要把近似写法当成另一种独立变化术，也不要把它重复计入全变化术清单。

🔴 风险4：只看旧攻略

旧页面曾把相近写法拆成两项，这是错误信息。本页已按 Dark Thunder、Ma Tianba 与全10种变化术清单重新校正。

6. 附带收获

完成马天霸任务链的完整收益。

收益类型说明
Dark Thunder / 黯雷变化术马妖形态，雷鞭攻击，雷属性免疫
马天霸图鉴词条影神图五章全部对话后自动解锁完整词条
全变化术收集进度+1收集要素10种已核实变化术之一
💡 NG+提示

若本周目错过马天霸链条，通常需要在下一周目重新按五章路线取得 Dark Thunder / 黯雷。
